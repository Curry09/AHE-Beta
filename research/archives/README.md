# Archived records

See [the research index](../README.md) for source versions and reproduction
requirements. Directory names identify the original research collection:

- `harness-suite-20260920/`: frozen tasks, experiment definitions and launchers.
- `public-bench-pilot/`: former pilot workflows and recorded comparisons.
- `public-templates/`: former public templates, separate from frozen configs.
- `legacy-materials/`: former seed pools and source persona collections.
- `legacy-runtime/`: former v1 runtime, migration tools and their tests.

These records do not extend the capabilities of the current experiment CLI.
