# Weekly notes helper

Build a small Python command-line tool for my weekly work notes. I want to keep
notes in a local UTF-8 JSON file, add an entry with a date and free-form text,
and list entries for a chosen ISO week in chronological order. Support multiple
entries on the same date, preserve Unicode text, and explain invalid dates or
malformed input without overwriting existing notes.

Use only the Python standard library. Include a README with commands for adding
and listing notes, and a few visible checks for the main behavior. Keep everything
in this task workspace; no network access, external services or credentials are
needed.

This is an original example of a user's task and is not taken from a benchmark.
Replace it with your own instruction before importing if you want a different task.
