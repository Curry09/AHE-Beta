# 2026-09-28 开源整理设计记录

本轮授权范围为两个仓库的首次开源准备，许可证由维护者选择 MIT。原工作目录保留，修改位于独立准备分支；不执行公开、tag 或远端发布。

安装以声明依赖和锁文件为真源。本仓保留 package=false；OpenAgents 保持基础 CLI 轻量，NexAU 以可选 extra 安装。联合 flow 默认保持 standard，文档和跨仓检查明确显式 v0.2 的差异。

公开快照修复选择允许列表投影，而非对任意字符串做 token 正则替换：未知文本即使不含已知密钥形状也不能公开。告警只输出数量，Agent ID 变为序号，状态/时间/计数字段按类型和词表归一化。operator 显式提供的公开 ID/title 不被自动判断内容安全。代价是损失诊断细节和旧默认 URL；完整诊断继续留在原始本地记录。回归覆盖最新快照、时间线与索引中的敏感哨兵及正常进度保留。

CI 扩展到 evaluation、两侧 UI、wheel 安装与跨仓解析。离线 demo 显式使用 ScriptedPersonaClient，不根据 ambient API key 自动选择 LLM。真实模型/容器认证与研究素材许可不能由离线测试替代，列入发布待办。
