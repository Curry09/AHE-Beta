# Unified held-out evaluation contract

One root `evaluation.yaml` selects the fixed task set, supported harnesses, role-specific models and concurrency. Credentials are environment-variable references and are never frozen into manifests. Former schema-2 JSON files are historical records, not operator configuration.

Official task wall-clock budgets, hidden tests and grading criteria remain task-owned. One source archive serves all task budgets; request options are applied only in generated runtime copies. User simulation and actor solving share the task budget. Native CC/Meta keep their own interaction mechanisms.

The read-only feedback persona and exact official opening are fixed for this protocol. The actor and its commands freeze before post-session subjective rating. Retrospective rating consumes only original persona and saved user-visible dialogue; official grades and private actor reasoning are excluded. Incomplete evidence stays unavailable. Valid ratings are reused.

Resume reattaches to the existing worker/process identity. Grader or experience recovery does not relaunch the actor. A new experimental run must be explicit. Official passing artifacts retain a positive task score even if execution reached a deadline. Infrastructure/grader failures remain invalid and are reported separately.

Raw response capture records what was returned, without text truncation; interrupted or opaque transports expose their limitations. CC captures its native CLI trajectory, not raw Node HTTP. Runtime records are private by default and publication uses a separately sanitized export.
